# Differential Equations Modeling Projects

This repository contains beginner-to-intermediate applied mathematics projects using Python, NumPy, Matplotlib, and numerical methods.

## Prjects

### Coffee Cooling Model 

Models the cooling of coffee in a ceramic mug using Newton's Law of Cooling: 

dT/dt = -k(T - T_room)

Synthetic temperature data was compared against Euler method approximations for several cooling constants. The best tested value was approximately k = 0.025

### Predator-Prey Model

Numerically simulates the Lotka-Volterra predator-prey equations. 

### Projectile Motion

Models projectile motion with and without air resistance. 

### Heat Equation

Uses finite differences and numerical ODE solving to approximate a 1D heat equation.
